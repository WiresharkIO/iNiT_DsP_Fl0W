__: Filter Approximation Types (in this project Butterworth and Elliptic) :__

How theorotically, the filter approximation types are charaterized and defined!!

> Butterworth filter:

Known for a "maximally flat" response in the passband, meaning no ripples, but has a slower roll-off (transition from pass to stop).

> Elliptic (Cauer) filter:

Provides the steepest, fastest cutoff of any filter for a given order, but has ripples in both the passband and stopband.
